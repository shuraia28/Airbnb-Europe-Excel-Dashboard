## 📌 Introduction
This project presents an interactive Airbnb Europe Dashboard built with 
Microsoft Excel, analyzing Airbnb listing data across 9 major European cities. 
The goal is to uncover pricing patterns, guest satisfaction trends, and 
room type distributions to support data-driven decisions in the 
short-term rental market.

## 🎯 Project Focus
- **Price Analysis:** Understanding average pricing across European cities
- **Guest Behavior:** Weekday vs Weekend booking patterns
- **Room Type Insights:** Distribution of Entire home, Private room, Shared room
- **Location Impact:** City centre and metro distance effect on listings
- **Satisfaction Metrics:** Cleanliness and guest satisfaction across cities

## 🛠️ Tools Used
- **Microsoft Excel** — Dashboard creation and data visualization
- **Pivot Tables** — Data summarization and aggregation
- **Slicers** — Interactive filtering by City, Room Type, and Day
- **Excel Charts** — Bar charts, Donut charts, Line charts

## 📂 Dataset
- **Domain:** Airbnb Europe short-term rentals
- **Cities Covered:** Amsterdam, Athens, Barcelona, Berlin, 
  Budapest, Lisbon, Paris, Rome, Vienna
- **Key columns:** City, Price, Day, Room Type, Person Capacity, 
  Superhost, Cleanliness Rating, Guest Satisfaction, Bedrooms, 
  City Centre Distance, Metro Distance, Attraction Index, Restaurant Index

## 📊 Dashboard Features

| Visual | Description |
|--------|-------------|
| KPI Cards | Guest Capacity, Average Price, Satisfaction %, Cleanliness Score |
| Day-Wise Guest | Weekday vs Weekend guest distribution (Donut chart) |
| Room Type Superhot % | Superhot listings by room type (Donut chart) |
| Restaurant & Attraction Index | City-wise comparison (Bar chart) |
| City Centre & Metro Distance | Average distance by city (Bar chart) |
| City-Wise Price & Guest | Total price and guest capacity trend (Combo chart) |
| Interactive Slicers | Filter by City, Room Type, and Day |

## 🔍 Methodology

### 1. Data Collection & Preparation
- Imported raw Airbnb Europe dataset into Excel
- Cleaned and formatted columns for consistency
- Normalized pricing and index values for comparison

### 2. Exploratory Data Analysis
- Used Pivot Tables to summarize data by city, room type, and day
- Calculated average price, satisfaction, and cleanliness scores
- Identified weekday vs weekend booking patterns

### 3. Dashboard Design
- Built interactive dashboard with slicers for City, Room Type, and Day
- Combined multiple chart types for comprehensive view
- Applied consistent color theme for professional presentation

## 📈 Key Findings
- **Average Price:** $260 across all European cities
- **Guest Satisfaction:** 93% average satisfaction rate
- **Cleanliness Score:** 9.44 out of 10
- **Top City by Price:** Paris and Rome show highest pricing
- **Weekday vs Weekend:** Nearly equal distribution (67K vs 68K guests)
- **Room Type:** Private rooms dominate listings (30% Superhot)
- **Best Location:** Cities with lower city centre distance 
  command higher prices

## 💡 Conclusion
This Excel dashboard provides a comprehensive overview of Airbnb 
listings across Europe. The interactive slicers allow users to 
filter by city, room type, and day — enabling quick identification 
of pricing trends, guest preferences, and location impacts. 
The analysis highlights significant variation in pricing and 
satisfaction across different European cities and room types.
